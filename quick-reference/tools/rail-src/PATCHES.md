# Rail — patched source for modern compilation (arm64/macOS)

Original source: [CTAN support/rail](https://ctan.org/pkg/rail) (Rail, Version 1.2 #1).
This C program, distinct from `rail2js` (in `../mkdocs/tools/rail2js-src`), compiles the
`\begin{rail}...\end{rail}` sections of the LaTeX document (`rail.sty`) into syntax
diagrams (`.rai` -> `.rao` file), used by `../Makefile` (target `faust-quick-reference.pdf`).

The code dates from the 1990s (K&R/pre-ANSI C) and no longer compiles as-is with a modern
compiler (Clang on macOS). Three minimal fixes were applied on top of the original CTAN
archive:

1. **`rail.c`**: the K&R signature of `main(argc,argv)` declared `argc` as `unsigned`.
   Clang requires the first parameter of `main` to be typed `int`. Since `argc` is not
   used anywhere else in the file, it was retyped to `int`.

2. **`rail.h`**: added `#define YYSTYPE_IS_DECLARED 1` right after the
   `typedef union {...} YYSTYPE;`. Without this macro, the `gram.h` generated by bison
   redefines its own `typedef int YYSTYPE;` (bison only detects an existing definition
   via this macro or `#define YYSTYPE`, not via a plain `typedef`), which causes a
   type-redefinition error at compile time.

3. **`Makefile`**: added `-std=gnu89 -Wno-implicit-int -Wno-implicit-function-declaration
   -Wno-return-type -Wno-deprecated-non-prototype` to `CFLAGS`, to tolerate the K&R style
   (function declarations without an explicit return type, non-prototyped functions)
   that modern Clang otherwise treats as hard errors (ISO C99+).

No change was made to the grammar or to the program's behavior: the generated `.rao`
output is strictly identical (byte for byte, except for the header comment quoting the
file name) to the one produced by older versions of the binary.

## Building

`../../Makefile` (target `faust-quick-reference.pdf`) depends on `tools/rail-src/rail`
and builds it automatically on demand, so under normal use there is nothing to do
manually. To build it explicitly (e.g. from the repository root):

```bash
make rail
```

or directly:

```bash
cd quick-reference/tools/rail-src
make
```

Requires `bison`/`flex`/`gcc` (or `clang`), all present by default on macOS with the
Command Line Tools.
